# Посмотри в окно

Учебный проект Яндекс Практикума: приложение для просмотра видео из разных городов с поиском по городу и времени суток.

Готовая разметка и JavaScript дополнены CSS: лейаутом, оформлением видео и карточек, кастомными чекбоксами и состояниями фокуса, наведения и нажатия. Для просмотра откройте `index.html` в браузере; загрузке видео нужен интернет.

Репозиторий: https://github.com/globalarray/posmotri-v-okno-ad
